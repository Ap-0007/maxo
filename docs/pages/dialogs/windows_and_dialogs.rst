================
Окна и диалоги
================

В ``maxo.dialogs`` интерфейс пользователя строится из окон (``Window``), которые объединяются в диалоги (``Dialog``).

Window
======

``Window`` - базовый кирпичик интерфейса. Каждое окно соответствует одному сообщению бота с клавиатурой. Окно привязывается к конкретному состоянию конечного автомата (``State``).

Создание окна:

.. code-block:: python

    from maxo.dialogs import Window
    from maxo.dialogs.widgets.text import Const
    from maxo.fsm import State, StatesGroup

    class MySG(StatesGroup):
        first = State()

    window = Window(
        Const("Текст окна"),
        state=MySG.first,
        # Опционально: disable_web_page_preview, parse_mode
    )

Двойной рендер медиа на iOS
===========================

В клиенте MAX на iOS (iPhone/iPad) есть баг рендеринга при редактировании
сообщения с медиа. Если у сообщения **уже есть** прикреплённые фотографии или
видео и это сообщение редактируется снова на сообщение с фото или видео (медиа
заменяется на медиа), клиент показывает противоречивое состояние:

- **Фото**: отображается старое превью, но при открытии показывается новое.
- **Видео**: отображается новое превью, но при воспроизведении играет старое.

Баг проявляется при редактировании сообщения (``ShowMode.EDIT``, а также
``ShowMode.AUTO``, который по умолчанию приводит к редактированию). На ``SEND``,
``DELETE_AND_SEND`` и ``NO_UPDATE`` бага нет, потому что там отправляется новое
сообщение или ничего не меняется. Баг воспроизводится и на одиночном фото или
видео, и на нескольких медиа в одном сообщении; других типов вложений
(аудио, файлы) он не касается. На Android и в вебе проблема не наблюдается.

Обойти баг помогает флаг ``two_step_media_edit`` у ``Window``. Когда он включён,
редактирование фото/видео на другие фото/видео выполняется в два шага:

1. Обновляется текст и клавиатура, медиа убирается.
2. Медиа возвращается, текст и клавиатура сохраняются.

Двойной рендер заставляет клиент iOS корректно обновить и превью, и сам файл.

.. code-block:: python

    window = Window(
        DynamicMedia("photo"),
        Const("Текст окна"),
        state=MySG.first,
        getter=media_getter,
        two_step_media_edit=True,
    )

.. note::

   Флаг по умолчанию выключен: двойной рендер удваивает число запросов к API.
   Чтобы окно не «моргало» медиа на каждом ререндере, ``maxo`` пропускает
   двойной рендер, когда токены всех новых медиа известны заранее
   (``media_id`` задан явно или медиа загружалось по ``path`` и токен найден в
   кэше ``MediaIdStorage``) и совпадают со старыми - значит, медиа не менялось.
   Если хотя бы одно медиа задано по ``url``, его токен заранее неизвестен,
   поэтому двойной рендер выполняется при каждом редактировании. Если между двумя шагами произойдёт
   сбой (например, сетевая ошибка), сообщение может остаться без медиа до
   следующего успешного ререндера. Подробности бага - в
   `issue #156 <https://github.com/K1rL3s/maxo/issues/156>`_.

Dialog
======

``Dialog`` - это набор окон, связанных логикой переходов. Диалог управляет жизненным циклом окон и хранит их общее состояние.

.. code-block:: python

    from maxo.dialogs import Dialog

    dialog = Dialog(
        window1,
        window2,
        window3,
        # другие окна...
    )

.. important::

   Все окна внутри одного диалога **должны** принадлежать одному ``StatesGroup``.

Жизненный цикл диалога
======================

Диалог можно рассматривать как функцию, которая:

1. Запускается (вызов через ``DialogManager.start()``)
2. Получает данные (аргумент ``start_data``)
3. Меняет внутренние состояния (переключение между окнами)
4. Завершается (возврат через ``DialogManager.done()``)
5. Может возвращать результат (параметр ``result``)

Вы можете перехватывать эти события с помощью параметров ``on_start``, ``on_close``, ``on_process_result`` при создании ``Dialog``:

.. code-block:: python

    from maxo.dialogs import Dialog, DialogManager

    async def on_dialog_start(start_data: dict, manager: DialogManager):
        print("Dialog started with data:", start_data)

    dialog = Dialog(
        window,
        on_start=on_dialog_start,
    )
